# Лабораторна робота №4: Робота з DOM, подіями та формами

**Мета:** закріпити практичні навички роботи з HTML-формами та подіями в JavaScript: перевіряти заповнення форми, обробляти вибрані відповіді, відображати результат на сторінці та відновлювати початковий стан тесту.

## Файли лабораторної роботи
- `index.html` — розмітка сторінки, форма (з атрибутом `novalidate`), кнопки **Submit answers** і **Retry**, блоки для повідомлення (`#quiz-message`) і результату (`#quiz-result`), підключення JavaScript-файлів.
- `quiz-api.js` — питання, варіанти відповідей і правильні відповіді. Функція `fetchQuizQuestions()` повертає готовий масив даних замість запиту до сервера.
- `app.js` — створення питань на сторінці, перевірка заповнення й правильності відповідей, підрахунок результату, підсвічування, блокування завершеного тесту та повторне проходження.

## Запуск коду
Відкрийте `index.html` у веббраузері (Chrome або Edge). Локальний сервер не потрібен. `index.html` спочатку підключає `quiz-api.js`, а потім `app.js`. Оформлення Bootstrap завантажується з інтернету. Можливі помилки видно в DevTools (F12) → Console.

## Завдання

### Завдання 1. Перевірка заповнення тесту через JavaScript
Функція `isQuizComplete(questions)` перевіряє, чи в кожному `fieldset` є вибраний перемикач (`input[type="radio"]:checked`). Якщо хоча б одне питання без відповіді, обробник `submit` показує в HTML повідомлення «Дайте відповідь на всі питання» і завершується: правильність не перевіряється, нічого не підсвічується, форма не блокується, вибрані відповіді зберігаються. Після заповнення всіх питань і повторного натискання **Submit answers** повідомлення зникає. Атрибут `novalidate` збережено, `required`, `checkValidity()` і `reportValidity()` не використовуються.

### Завдання 2. Підрахунок і відображення результату
Під час перевірки повністю заповненого тесту рахується кількість правильних відповідей (порівнянням вибраного значення з `data-correct-answer` питання). Загальна кількість питань береться з HTML — кількість елементів `fieldset` у формі. Результат виводиться під кнопками, наприклад: «Правильних відповідей: 2 із 3.». Підсвічування збережено (правильна — зелена, неправильна вибрана — червона), після перевірки перемикачі й кнопка **Submit answers** блокуються.

### Завдання 3. Повторне проходження тесту
Кнопка **Retry** (`type="button"`) доступна і під час заповнення, і після завершення тесту. Її обробник скидає всі вибрані відповіді, прибирає підсвічування та класи `is-valid` / `is-invalid` (через `clearAnswerStyles()`), очищає результат і повідомлення, розблоковує перемикачі та кнопку **Submit answers**. Сторінка не перезавантажується.

## Самоперевірка
| Ситуація | Результат |
|---|---|
| Нічого не вибрано | повідомлення, форма доступна |
| Вибрано лише частину відповідей | перевірки немає, вибір збережено |
| Після повідомлення заповнено решту | повідомлення зникає, з'являється результат |
| Усі відповіді правильні | «Правильних відповідей: 3 із 3.» |
| Є неправильні відповіді | кількість і підсвічування відповідають вибору |
| Retry під час заповнення / після повідомлення | вибір і повідомлення очищено |
| Retry після завершення | результат і підсвічування очищено, форма розблокована, новий результат при повторному проходженні |
| Консоль браузера | помилок JavaScript немає |
